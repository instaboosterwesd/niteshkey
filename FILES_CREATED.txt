==================================================
ARCHITECTURAL OVERVIEW
==================================================

AUTHENTICATION:
- Supabase email/password authentication
- Three user roles: student, teacher, parent, admin
- Secure session management
- Protected routes for authenticated users

PAGES & ROUTING:
Public:
  / ............................ Home page
  /login ....................... Login page
  /signup ...................... Sign up page

Protected (Auth Required):
  /dashboard ................... Main student dashboard
  /games ....................... Learning games library
  /profile ..................... User profile & achievements

GAMIFICATION SYSTEM:
XP System:
  - Level-based progression (quadratic scaling)
  - Formula: Level N requires N² × 100 XP
  - Tracks total XP and current level

Rewards:
  - Question rewards: Easy (10 XP/5 coins), Medium (25/15), Hard (50/30)
  - Streak bonuses: 3+ days (1.1x), 7+ (1.25x), 14+ (1.5x), 30+ (2x)
  - Daily login bonuses: 50+ XP, 25+ coins

Badges (Unlockable):
  - XP-based: first-steps, explorer, scholar, master
  - Streak-based: on-fire, unstoppable, legendary
  - Activity-based: quick-learner, dedicated, committed
  - Perfection: perfectionist, flawless

STYLING:
- Tailwind CSS for utility-first styling
- CSS variables for theme colors (oklch color space)
- Custom colors: --xp (green), --coin (gold), --streak (orange)
- Dark mode support via .dark class
- Responsive design with md: breakpoints

COMPONENTS STRUCTURE:
Presentational:
  - XPDisplay, CoinDisplay, StreakDisplay: Stats display
  - BadgeCard: Achievement badges
  - GameCard: Game catalog items
  - QuestionCard: Quiz interface
  - Navbar: Navigation bar

Smart/Container:
  - Dashboard: Stats aggregation
  - Games: Game catalog
  - Profile: User achievements
  - AuthContext: State management
